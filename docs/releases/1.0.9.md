Screens pick up updates by themselves, and shops can be removed from the online panel properly.

- New: after an update, every open screen reloads itself on the new version, so nobody has to close and reopen Aruna POS. A bill being rung up is never lost: that screen waits until the bill is paid or held, and shows "Reload now" meanwhile. (This starts with the next update after 1.0.9: screens still on 1.0.8 need to be reopened once.)
- Online panel: Cloud sync no longer shows a blank page when there is more than one shop.
- Online panel: the owner can remove any shop, the one being looked at included, or all shops at once. The warning says exactly what is deleted, and the shop's name (or REMOVE ALL) must be typed before it works.
- Online panel: with no shop linked, the sign-in page says so plainly. The panel shows its real version.
- Release builds retry a download when a server hiccups.
