The screen lock for people without a PIN.

- Fixed: someone with no PIN (for example the owner's account arriving from the online panel) was asked for a PIN when the screen locked. Now the locked screen opens on the password box and says so; another person can still switch in with their own PIN.
- New: My profile → Set my PIN (or Change my PIN). Type your password, then a 4–6 digit PIN. Every PIN in the shop is different.
